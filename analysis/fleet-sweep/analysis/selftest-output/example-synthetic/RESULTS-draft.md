# Fleet sweep (study 2, PLAN-v5): results draft

Generated by `analysis/score.py` (PLAN-v5; the default `--plan v5`). Numbers are filled in by the script; the prose around them is to be written. Every result is labelled **[confirmatory]** or **[descriptive]** as fixed before the sweep (PLAN-v5 section 5). Review is automated and fast (a fresh default-effort call per change, 10-30 s), so the study asks what limits the fleet when review does not: the workers' own scaling (SCALE, primary), collisions (COLL), and quality (ESC). There is no review-capped rival.

Sizes: 1, 12. Windows: 15 (12 at N = 1, 3 at N = 12). Over-dispersion CV fixed at 0.3. Constants: alpha = 0.1, beta = 0.01, p = 0.005.
